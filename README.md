# ABI Consultancy — Five-page static website

Pages: `index.html` (Home), `services.html`, `training.html`, `about.html`, `contact.html`.

## Deploy to existing GitHub Pages
1. Back up your current repository files.
2. Upload these files to the **root** of the existing `abi-consultancy-website` repository, replacing the existing `index.html`, `styles.css`, `script.js`, and `favicon.svg`; add the four new page files.
3. Commit to the existing publishing branch (`main`) at the repository root.
4. Wait for GitHub Pages to deploy, then test all five pages on mobile and desktop.

The contact form opens the visitor's email application; it does not store enquiries on a server. Keep all domain and Google Workspace email DNS records unchanged. Confirm service availability and details before launch.
